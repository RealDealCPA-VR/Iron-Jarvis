# What changed in Iron Jarvis

*One paragraph per version, made from the Handbook's own sections. Settings › System › Updates shows the paragraph for the version you are on; the Handbook holds the full story of each change.*

## v1.560.0

**Browse and download models, with what fits this PC.** Model servers now has a second tab, **Models**: a model library in the style of LM Studio.

## v1.559.2

**A deleted session's copies of your files always go.** When you delete a Build › Code session in a folder without git, Iron Jarvis now removes its copies of your files even when one of them was in use at that moment.

## v1.559.0

**The night review leaves suggestions for the morning.** Iron Jarvis can now look at what went wrong during the day while your PC is idle at night, and leave suggestions in **Improvements** for you to accept or decline in the morning.

## v1.558.1

**New conversation works the moment a sidebar reply ends.** In the browser sidebar, New conversation now works as soon as a reply's end is on screen.

## v1.558.0

**Photos, files and voice notes reach Jarvis from your phone.** Send Jarvis a photo of a page, a PDF, a spreadsheet or a voice note in Telegram, Slack or email, and it works on it the way it works on a file you drop into Chat on this PC.

## v1.557.0

**The `/` list in Build › Code works before a session starts.** Type `/` in Build › Code's start box (the box you see before any session is open) and the coding tool's own commands and skills are listed above the box, as they already were in an open session.

## v1.556.0

**Pick up where you left off in a folder.** Start a new chat or a new coding session in a folder you have worked in before, and a short card under the folder chip says what happened there last time.

## v1.555.0

**Results come home to the chat that asked.** Something you set up from a chat now reports back into that same chat.

## v1.554.0

**Agents and terminal help know what was done before.** An agent you give a job in a folder now starts knowing what was done there before, the way a chat in that folder already does: the pieces of earlier work on Iron Jarvis's own record (each chat, coding session or agent run there, how it ended and the files it wrote) and, for work in exactly that folder, its checked recap (Done, Decided, Open).

## v1.553.0

**Before and after pictures under a coding reply.** When a reply in a coding session (Chat › Code) changes how a page looks, you can see it: two pictures under the reply, the page **Before** the change and **After** it, each with the page's address and the time.

## v1.552.0

**Choose what each of your other computers may do.** Each computer you paired with this one now has its own switches: what it may do HERE.

## v1.551.0

**Iron Jarvis checks every Build › Code reply.** Whichever coding tool did the work in Build › Code (Claude Code, Codex, Pi, OpenCode, Grok or Antigravity), its reply now ends the same way.

## v1.550.0

**The Timeline shows the models that did the work.** A coding session's **Timeline** tab now opens on the models that did the reply, each one a card, joined by arrows where one handed work to another.

## v1.549.0

**Press a figure to see where it came from.** When a reply is about a file you gave Iron Jarvis or asked it to read (a PDF, a Word file, a text or CSV file, or a saved spreadsheet), the figures in the reply are now links.

## v1.548.1

**Copy as a fix request leaves out Local only work.** A coding session you keep **Local only** is now never in the report that "Copy as a fix request" makes for a coding agent: not its errors, its commands, a reviewer's findings or even its name.

## v1.548.0

**Scroll back to the start of a long chat.** In a long chat, scroll up and the earlier messages load in place, back to the first one kept.

## v1.547.0

**Ask what was done before, in any chat.** You can now ask Iron Jarvis about earlier work in plain words, in any chat and from an agent: "what did we do in this folder?", "what have we done on the price list?", "have I worked on this before?".

## v1.546.2

**A task from another computer brings as much of its chat as fits.** When one of your other computers sends this one a task ("@desk read the notes"), the chat it was asked in rides along so the work starts with the same background.

## v1.546.1

**Slack and email say when they could not take a file.** A file you send Jarvis in Slack or by email now gets a plain answer that it could not be used, the way Telegram already did, instead of silence.

## v1.546.0

**Rewind works in folders without git too.** "Rewind to here" can put a folder's files back as they were when a message started (v1.543.0).
