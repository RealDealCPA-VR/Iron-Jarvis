# What changed in Iron Jarvis

*One paragraph per version, made from the Handbook's own sections. Settings › System › Updates shows the paragraph for the version you are on; the Handbook holds the full story of each change.*

## v1.580.0

**What everything cost, by folder, client, automation and agent.** Usage has a new card, **What it cost**, with a **By** switch: **Folder**, **Client**, **Automation** and **Agent**.

## v1.579.0

**Review comments arrive in the coding session.** When people comment on a pull request a coding session (Chat › Code) opened, their comments now come to that session.

## v1.578.0

**Start coding work from your phone.** Text Iron Jarvis from Telegram, Slack or email: "in the website folder, fix the broken contact form", or the command `/code website: fix the broken contact form`.

## v1.577.0

**Big extensions work the way you set them.** An extension with dozens of tools, such as an accounting app, now works through chat the whole way: Jarvis reaches the tool a job needs, asks you only where you want to be asked, and can run several of the extension's calls at once.

## v1.576.0

**Hand Jarvis a recording.** Drop a meeting recording, a call or a voice memo into a chat (an .m4a, .mp3, .wav, .ogg or another sound file, or a video, whose sound is used) and ask what you want to know, such as "what did we decide?".

## v1.575.0

**Auto in chat: tools Jarvis looks up no longer ask every time.** In a chat, Iron Jarvis looks up which of its tools fit your message and brings them into the reply.

## v1.574.0

**Your day: everything Iron Jarvis changed, and Undo for one or many.** The Activity page has a second tab, **Your day**, beside the **Timeline** (Everything › Activity, or Ctrl K and "your day").

## v1.573.0

**Local models waste fewer steps in a coding session.** A benchmark of a local model (GLM) in **Chat › Code** showed that no task was lost to a mistake with a tool, but about 6 in every 100 tool calls were spent on three avoidable ones.

## v1.571.0

**A coding session is told to take care.** When Iron Jarvis itself writes code (**Chat › Code**), the instructions it gives the model said how to do a task, and little about how to behave in your project.

## v1.570.0

**Auto reaches helpers and handed-off work.** Under **Auto**, the quick check that lets routine commands through worked only in a reply.

## v1.569.0

**Auto asks less: your own pages open, and the quick check knows your folder.** With the approval level on **Auto**, Iron Jarvis still stopped to ask about work nobody needed to approve, and a card nobody saw held the work for hours.

## v1.568.0

**Say "when this happens, do that" once: a folder or a download can start a rule.** Say one sentence in chat, such as "when a PDF lands in Intake, read it and file it by sender", and Iron Jarvis makes **one rule**.

## v1.567.0

**See what memory gave a reply, and fix a preference.** When a chat reply was given things Iron Jarvis remembers (your preferences, a client's preferences, earlier work in the folder and its recap, notes, earlier chats and agent runs, files, project knowledge), the reply says so.

## v1.566.0

**Changes you accepted show their result.** When you accept a change from **Improvements**, Iron Jarvis now counts how the work went before and after it, from its own records, and shows the result under the waiting suggestions, in **Results of changes you accepted**.

## v1.565.1

**Two changes at once in Build › Code wait for each other.** Two small fixes for moments when two things change the same session or the same files at once.

## v1.565.0

**Finished files come back to your phone, and approvals have buttons.** Ask Jarvis from Telegram, Slack or email to "turn this into a spreadsheet", and the answer arrives with the spreadsheet.

## v1.564.0

**Sort a scanned pile into its documents.** One PDF that holds a whole scanned pile becomes separate, named documents in their folders, after you check the plan.

## v1.563.0

**Quick Ask: the answer appears right there.** Press **Ctrl+Shift+Space** in any program (Help › Keyboard shortcuts shows the key that is live, if another app holds that one), type your question, and press Enter.

## v1.562.0

**Rehearse a rule or a schedule before it runs for real.** A rule or a schedule can now run once as a **rehearsal**.

## v1.561.0

**Commit and Open a pull request in Build › Code.** When a Build › Code reply is done (and Iron Jarvis has checked it), a small box under it offers **Commit** with the message already written, then **Open a pull request**: one press each.
