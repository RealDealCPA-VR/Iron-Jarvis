# What changed in Iron Jarvis

*One paragraph per version, made from the Handbook's own sections. Settings › System › Updates shows the paragraph for the version you are on; the Handbook holds the full story of each change.*

## v1.472.2

**Test results you can trust after a quick fix.** **A test run right after an edit always reads the new code.** Python keeps a compiled copy of each file and reuses it when the file's time (to the second) and size have not changed.

## v1.472.0

**Long coding sessions stream smoothly.** Nothing on screen changes.

## v1.471.1

**Three more requests read right.** Nothing on screen changes.

## v1.471.0

**Faster tool calls, better reading of requests, sturdier scripts.** Nothing on screen changes.

## v1.470.2

**The installer is signed.** Since v1.470.1 the Windows installer is signed as **RealDealCPA.Ai LLC**.

## v1.470.1

**The installer can be signed.** The Windows installer can now be signed as **RealDealCPA.Ai LLC**, through Microsoft Artifact Signing.

## v1.469.1

**Links to another workbook follow the folders Jarvis may read.** A formula can link to another workbook, for example a summary sheet that reads a figure from a client's own file.

## v1.469.0

**Matching two lists, and Excel's features in a saved workbook.** **Matching two lists of transactions.** Ask Jarvis to reconcile a bank statement to the books, tie a sub-ledger out to its control account, or compare two exports, and it now does the matching in code instead of reading the rows.

## v1.468.0

**Jarvis beside Excel.** Jarvis can now sit beside your workbook and know what you have selected, the way a panel inside Excel would.

## v1.467.0

**How a number is built, what-if and goal seek.** Jarvis can now explain a figure in a spreadsheet, tell you what would change it, and take you to the cell.

## v1.466.0

**Working in a workbook that is open in Excel.** Until now Jarvis worked on saved files, so a workbook had to be closed first.

## v1.465.0

**Spreadsheets Jarvis understands and works out itself.** Jarvis used to read a workbook as a grid of cells and leave every formula to Excel.

## v1.464.0

**Starter skills you can load.** A skill is a set of instructions Jarvis follows for one kind of task, such as "review a bank reconciliation" or "write release notes".

## v1.463.0

**Reading web pages works on more sites; page screenshots work again.** **Reading a web page.** When Jarvis reads a page for you, it used to tell the site it was the Chrome browser.

## v1.462.0

**A missing file says where it really is.** When an agent or a coding session's helper asks to read or edit a file that is not there, the refusal now also says where a file of that name is in the same folder: "no such file: apps/shared/src/tokens.ts.

## v1.461.0

**Tools you already have are listed, not offered again.** When you bring tools from Claude, Codex, Cursor and your other apps (Settings › Tools › Add a tool), or paste a config, a tool that is already in Iron Jarvis now sits in a short **Already added** list under the new ones.

## v1.460.0

**Box starts again, and a broken extension says so.** Connecting Box saved its keys, but the extension never started: its row read "Didn't start: the extension's server exited (exit code 1)" with an `ImportError` underneath.

## v1.459.0

**Six small fixes.** **Compact in Build › Code for Pi, OpenCode and Grok.** The Session tab's Context drop-down now has "Compact session" for these too (it said they "compact by itself").
