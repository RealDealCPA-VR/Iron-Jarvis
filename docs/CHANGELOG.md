# What changed in Iron Jarvis

*One paragraph per version, made from the Handbook's own sections. Settings › System › Updates shows the paragraph for the version you are on; the Handbook holds the full story of each change.*

## v1.450.0

**The first run, and every connection, in plain words.** **No Claude Code or Codex yet?** The connect door offers "Install Claude Code for me" / "Install Codex for me": a Build terminal opens and runs the vendor's own installer where you can watch it.

## v1.449.0

**Did it work? The app tells you, everywhere.** Every place that reports on work now gives the same, plain verdict.

## v1.448.0

**Chat configures the rest: models, tool servers, web services.** Three more things you can set up by asking, and four small honesty fixes.

## v1.447.0

**Build › Code: more of each tool, and a calmer look.** **Antigravity.** **Your own Antigravity agents.** The agents `agy agents` lists appear in the mode menu after Antigravity's own modes.

## v1.446.0

**Nothing goes quiet on you.** The second group from the ease-of-use review: things that failed, waited or paused without telling you.

## v1.445.0

**Your first ten minutes, smoother.** An ease-of-use review (docs/EASE-OF-USE-REVIEW-2026-11-07.md) walked the app as a brand-new user.

## v1.443.0

**Antigravity's models and sign-in, and a chat that works in a folder.** **Antigravity's models show up before you start a session.** Once you have signed in to Antigravity (run `agy` in a terminal and sign in with Google), Build › Code's model menu lists Antigravity's own models, each with the thinking levels it takes, before any session has run.

## v1.442.0

**Setup from chat, proven on 30 requests.** The chat-first plan set itself one test: 30 everyday setup requests, asked in plain words.

## v1.441.0

**Build › Code catches up with each tool.** Build › Code runs your own coding tool (Claude Code, Codex, Pi, OpenCode, Grok or Antigravity) and shows its work.

## v1.440.0

**Loose ends tied up.** **Delete a goal you made in chat** from the Autonomy page: press Delete twice.

## v1.439.0

**Antigravity in the Code view, and usage you can check now.** **Google Antigravity is the sixth tool in Build › Code.** If Google's Antigravity CLI (`agy`) is installed on this PC, the Code view offers it beside Claude Code, Codex, Pi, OpenCode and Grok.

## v1.438.0

**More setup from chat.** Each of these shows a card before anything changes, and each change has an Undo that puts back only what that change did.

## v1.437.0

**Set up a coding session before it starts.** The box you start a Chat › Code session in now has the same row as an open session: how much it asks (with Plan), **Try on…**, **Team**, the effort level (only for a model that offers levels) and the model picker with your Claude Code and Codex accounts.

## v1.436.0

**A button to the right page, and honest answers.** **One button when a step needs a page.** Ask chat to sign in to Claude Code, Codex or Grok, add a second account, sign in to Microsoft 365, get your Microsoft 365 admin's approval, set up Google or Slack, install the browser add-on, or pick a local model, and one button appears under the reply that opens the exact place.

## v1.435.0

**Projects, agents, apps and more from chat.** Each of these shows a card before anything changes, and each change has an Undo.

## v1.434.0

**Chat finds the right tool.** **Chat knows every setting by its name.** Ask "turn on follow-up suggestions", "use Ollama by default", "stop asking before every command" or "make the app dark", and chat offers the right setting.

## v1.433.0

**Seventeen fixes from the deep review.** A deep review of the whole app found 17 bugs.

## v1.432.0

**Build › Code's mode menu shows names only too.** The mode menu in Build › Code (the shield chip under the message box, and the one on a new session) now lists the modes by name only, the same way as the chat's approvals menu.

**The approvals menu shows names only.** The menu behind the shield chip in the chat box (in Chat and in Chat › Code) now lists the levels by name only, one line each:

## v1.428.0

**Microsoft 365, locked down for client data.** Microsoft 365 (Outlook, Calendar, OneDrive) is now set up the safe way for a firm that holds client information.
