# Calm UI wireframes (Phase 1)

ASCII wireframes for the six views the brief asks for. They show **layout and
hierarchy only**; the colours, type sizes and spacing come from the visual
system in `../AUDIT.md` section 8. Desktop is drawn at about 1280 px wide, and
each file also has a 390 px phone version.

| File | View |
|---|---|
| [home.md](home.md) | Home = a new chat (chat-first, composer focused) |
| [sidebar.md](sidebar.md) | Sidebar: four nav items, then conversations and projects |
| [settings.md](settings.md) | Settings: grouped sections, search, one Save |
| [command-palette.md](command-palette.md) | Ctrl+K: pages, settings, actions, chats |
| [config-card.md](config-card.md) | Inline "setting changed" card with Undo (and the ask-first variant) |
| [credential-card.md](credential-card.md) | Secure credential card (the key never enters the transcript) |

Legend: `[ Button ]` is a button and `( Primary )` the single primary action in a
view. `▾` marks a menu, `●` a status dot and `⌘K` the command palette (Ctrl+K on
Windows). `…` stands for truncated text.
