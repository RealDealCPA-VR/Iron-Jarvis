Let Iron Jarvis work in your tabs

The Iron Jarvis browser add-on installs with no access to any site. Chrome only lets a page ask for that access when you click a button yourself, which is what this page is for.

  • This version sees only the tabs you have open — their titles and addresses.
  • Reading what is on a page, and acting in one, arrive in later versions — and then only while you or an agent asks for it.
  • Everything runs on this computer, over 127.0.0.1.
  • You can withdraw this access at any time from chrome://extensions.

You can close this tab once access is granted.
