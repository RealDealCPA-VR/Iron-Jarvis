---
name: project-status-update
description: >-
  Write a project update for the people paying for or depending on the project.
---

Use this for a regular update to a sponsor, a client or a steering group.

1. First line: overall state in one word (on track, at risk, off track) and one sentence why.
2. Then:
   - **Progress since last update** against the milestones.
   - **Next** until the following update.
   - **Dates**: any that moved, the old date, the new date and the reason.
   - **Budget**: spent against plan, only from figures given.
   - **Risks and issues**: new, changed and closed.
   - **Decisions or help needed**: from whom, by when.
3. Report bad news plainly and early, with what is being done about it.
4. Use the same layout every time.
5. Do not round a late project up to "on track". If you do not know, say what is missing.
