---
name: work-breakdown
description: >-
  Break a goal into tasks small enough to assign, estimate and finish.
---

Use this when the user has a goal or a large task and needs a plan.

1. Start from the finished result and work backwards to what must exist.
2. Split the work into parts, then each part into tasks someone can finish in a few days or less.
3. For each task give: what "done" means, who does it if known, what it depends on, and a size (small, medium, large). Give hours or days only if the user asked or gave their own estimates.
4. Mark the tasks that block others, and the ones that can run side by side.
5. Call out anything nobody knows how to do yet as its own task: "find out how to".
6. Give the result as a table, in the order the work should happen.
7. Do not promise an end date from guessed sizes. Say what would be needed to give one.
