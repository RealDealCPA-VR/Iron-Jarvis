---
name: client-document-request
description: >-
  Write a clear list of the documents and answers a client must send, with a deadline.
---

Use this when the user needs information from a client for a tax return, a close or an engagement.

1. Start from what is already in hand. Never ask for something the user already has.
2. List what is missing as a numbered list. For each item say: what it is, for which period, and the form it should come in (PDF statement, export, photo).
3. Put the items the work cannot start without first.
4. Use the name the client would recognise ("your December bank statement for the account ending 4821"), not internal terms.
5. Give one deadline and say what it protects (a filing date, a meeting).
6. Say how to send the documents safely. Sensitive details (tax ID numbers, full account numbers, passwords) must never travel by ordinary email.
7. Draft it as an email for the user to review and send. Do not send it yourself.
