---
name: expense-categorization
description: >-
  Sort a list of transactions into accounts or categories, and flag the ones that need a person.
---

Use this when the user gives bank or card transactions and wants them categorised.

1. Use the client's own chart of accounts if you have it. If not, ask for it or state the standard categories you are using.
2. For each transaction give: date, payee, amount, category, and how sure you are (sure, likely, unsure).
3. Mark "unsure" and do not guess for: personal-looking spending, transfers between accounts, payments to people, large or unusual amounts, and anything that could be an asset instead of an expense.
4. Treat the same payee the same way every time. If you change your mind part way, go back and make them match.
5. Keep refunds and reversals with the original category, as negative amounts.
6. Total each category with a calculation tool or a formula, and check that the category totals add up to the grand total before you report them.
7. End with the questions for the client, one line each, so they can answer quickly.
