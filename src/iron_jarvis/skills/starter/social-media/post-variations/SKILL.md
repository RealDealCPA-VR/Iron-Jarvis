---
name: post-variations
description: >-
  Write one message as several posts, each fitted to a different platform.
---

Use this when the user has something to say and wants posts for more than one platform.

1. Fix the single point of the message and the one action wanted.
2. Write a version for each platform the user names, to that platform's habits:
   - LinkedIn: a strong first line, short paragraphs, a professional point of view.
   - Facebook: friendly, a little longer, a question to invite replies.
   - Instagram: the caption supports a picture; say what picture it needs.
   - X: one idea, very short.
3. Give two options for the first line of each.
4. Add hashtags only where they are normal for the platform, and few.
5. No claims, numbers or customer names the user did not give. Nothing about a client's private affairs.
6. Do not post. Give the drafts for review.
