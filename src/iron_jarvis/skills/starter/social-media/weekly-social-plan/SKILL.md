---
name: weekly-social-plan
description: >-
  Plan a week of posts: what goes out, where, on which day, and what each needs.
---

Use this when the user wants a simple posting plan they can keep up.

1. Ask how many posts a week they can manage and where, if not given.
2. Build a table for the week: Day, Platform, Topic, Type (tip, story, proof, offer, question), What is needed (photo, link, approval), Status.
3. Mix the types: mostly useful or interesting posts, at most one in four selling something.
4. Put anything tied to a date first.
5. Write the first line of each post so the plan is ready to use.
6. Note which posts can be made from one piece of work.
7. Do not schedule or post anything. This is a plan for the user to approve.
