---
name: sop-writer
description: >-
  Write a standard operating procedure: numbered steps someone new could follow without help.
---

Use this when the user wants a procedure, checklist or how-we-do-it document.

1. Ask, only if you cannot tell: who does this task, how often, and what "done" looks like.
2. Write the procedure with these parts:
   - **Purpose**: one sentence.
   - **When to use it** and **who does it**.
   - **Before you start**: what is needed (access, files, approvals).
   - **Steps**: numbered, one action per step, each starting with a verb. Put the exact name of the screen, file or button in the step.
   - **Check**: how to tell it worked.
   - **If something goes wrong**: the two or three most likely problems and what to do.
3. Write for someone on their first day. Explain any term the first time it appears.
4. Leave a line for "Owner" and "Last reviewed" so the document can be kept current.
5. If the user described a step loosely, write it as they said and mark it "confirm" rather than inventing detail.
