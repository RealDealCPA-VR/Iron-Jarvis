The inventory page in this folder needs a search box and a working "Low stock only" filter, and it must say how many items it shows. `UI.md` states exactly how the page must behave (the element ids, the texts, how the filters combine); build it that way in `static/index.html` and `static/app.js`.

The page is a real web page: start it with `python server.py --port 0` (it prints the address it listens on) and check it in a browser — type in the search box, tick and untick the checkbox, try a search that matches nothing — before you say it works. Stop the server you started when you are done (stop only that process: never end any other program on this computer; other Python programs may be running here, and they are not yours to stop). Keep `server.py` and `test_server.py` working, and do not change `data/items.json`.
